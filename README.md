# Reggi Lovvita Mulyasari - Professional Portfolio

## Deskripsi
Ini adalah portfolio profesional saya yang menampilkan informasi pribadi, pendidikan, pengalaman kerja, keterampilan, proyek-proyek, blog, dan formulir kontak. Desainnya modern, bersih, dan girly dengan fokus pada pengalaman pengguna yang nyaman.

Portfolio ini dirancang sebagai satu halaman statis dengan navigasi yang memungkinkan pengunjung menggulir ke bagian yang relevan saat mereka mengklik menu di atas.

---

## Fitur Utama
- **Navigasi Halus**: Klik menu di bagian atas untuk menggulir halaman ke bagian yang sesuai.
- **Tombol "Back to Top"**: Tombol muncul saat pengguna menggulir halaman lebih dari 200 piksel.
- **Formulir Kontak**: Pengunjung dapat mengirim pesan melalui formulir kontak menggunakan layanan [FormSubmit](https://formsubmit.co/).
- **Responsif**: Desain responsif untuk tampilan yang baik di perangkat desktop dan mobile.
- **Desain Modern**: Tema modern dengan warna pink lembut untuk kesan girly namun profesional.

---

## Struktur Folder
Portfolio ini hanya terdiri dari satu file HTML dan tidak memerlukan folder tambahan karena semua aset (seperti gambar) di-host secara eksternal.

- `index.html`: File utama yang berisi seluruh konten portfolio.

---

## Cara Menjalankan Proyek
1. **Unduh File**:
   - Klon repositori ini atau unduh file `index.html` secara manual.

2. **Buka di Browser**:
   - Buka file `index.html` di browser favorit Anda untuk melihat portfolio.

3. **Unggah ke GitHub Pages** (Opsional):
   - Jika ingin membuat portfolio online:
     1. Buat repositori baru di GitHub.
     2. Unggah file `index.html` ke repositori tersebut.
     3. Aktifkan GitHub Pages di tab **Settings** > **Pages**.
     4. Portfolio Anda akan tersedia di URL seperti `https://<username>.github.io/<repository-name>/`.

---

## Teknologi yang Digunakan
- **HTML5**: Untuk struktur halaman.
- **CSS3**: Untuk desain dan tata letak.
- **JavaScript**: Untuk fungsi-fungsi interaktif seperti gulir halus dan tombol "Back to Top".
